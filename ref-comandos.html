Git Comandos

Esta página é uma tabela de consulta: todos os comandos do Git que o guia ensina, agrupados pela tarefa que você quer fazer, com as opções mais usadas e um link para a aula onde cada um é explicado com calma, com saídas reais e exercícios. Use Ctrl+F no navegador para procurar um comando.

Como ler as tabelas
  • O que está entre < e > você troca pelo seu valor: git add <arquivo> vira git add index.html.
  • O que está entre [ e ] é opcional.
  • git 2.23+ marca comandos que não existem em versões antigas do Git (o guia usa o Git 2.53 do Ubuntu; confira a sua com git --version).
  • Os comandos marcados com ⚠️ podem apagar trabalho: leia a aula antes de usar.

Como apontar para um commit

Onde a tabela diz <commit>, você pode escrever qualquer uma destas formas:

FormaSignificaAula
a939be6O hash (o começo dele basta, se não for ambíguo).O Hash do Commit
HEADO commit atual.O que é HEAD
HEAD~1, HEAD~3Um, três commits antes do atual.O que é HEAD
main, origin/mainO último commit daquele branch (local ou remoto).O que é um Branch
v1.0.0O commit da tag.git tag
HEAD@{1}Onde o HEAD estava um passo atrás (do reflog).git reflog
main..contatoOs commits que estão no contato e não no main (em git log).Filtros e Formatos
