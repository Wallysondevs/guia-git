Git Glossário

O Git fala inglês, e as palavras dele aparecem em toda mensagem, tutorial e conversa de equipe: commit, branch, merge, push… Este glossário traduz cada termo, explica com uma frase simples e leva você à aula que trata do assunto. Os termos estão em ordem alfabética, pelo nome que você mais vai ver (em geral, o inglês).

Como usar
  • Use Ctrl+F no navegador para achar um termo, ou pule pela letra abaixo.
  • Entre parênteses, a tradução usada no guia. Em itálico, outros nomes para a mesma coisa.
  • Na mensagem do Git em português, alguns termos já aparecem traduzidos (No ramo main = "no branch main"; Arquivos não monitorados = arquivos não rastreados).

Os termos num desenho só

Boa parte do vocabulário aparece numa única saída real do git log --oneline --graph --all do repositório da Ana:

$ git log --oneline --graph --all
* 70a65a8 (bolo) Ajusta a farinha do bolo                « um commit no branch "bolo"
| * 152d79c (HEAD -> main) Atualiza o título do README   « HEAD: onde você está; main: o branch atual
|/                                                       « o ponto onde os dois branches se separam
* c8d0fdc (tag: v1.0) Adiciona receita de pudim         « uma tag: etiqueta fixa num commit
* 8426608 Adiciona cobertura de chocolate ao bolo        « 8426608: o hash (curto) do commit
* c94a9e3 Adiciona receita de bolo
* fe996fb Primeiro commit                                « o commit raiz: o primeiro, sem pai

A

TermoO que éAula
add (adicionar)Pôr uma mudança na área de preparo, para ela entrar no próximo commit: git add receita.txt.git add
alias (atalho)Um nome curto que você cria para um comando longo: git st = git status.Atalhos
amend (emendar)Refazer o último commit, para corrigir a mensagem ou acrescentar um arquivo esquecido. Gera um commit novo, com outro hash.--amend
ancestral comum (merge base)O último commit que dois branches têm em comum: o ponto onde eles se separaram. O merge de três vias compara tudo com ele.Merge de Três Vias
área de preparo (staging area, index, stage)A "sala de espera" do commit: o que você escolheu com git add e vai entrar no próximo commit. Nas mensagens: "Mudanças a serem submetidas".A Área de Preparo
author (autor) × committerO autor escreveu a mudança; o committer gravou o commit. Quase sempre é a mesma pessoa; diferem num cherry-pick, rebase ou patch aplicado por outra pessoa.Formatos do git log

B

TermoO que éAula
bare (repositório "nu")Um repositório sem pasta de trabalho, só com o histórico (o conteúdo da .git). É o que fica num servidor, para receber push.Repositório Remoto
bisect (dividir ao meio)Achar o commit que criou um bug testando o commit do meio, depois o do meio da metade… git bisect.git bisect
blame (culpar)Mostra, linha por linha, qual commit e quem mudou cada linha de um arquivo.git blame
blobO objeto em que o Git guarda o conteúdo de um arquivo (sem o nome).Como o Git Guarda
branch (ramo; nas mensagens, "ramo")Uma linha de trabalho independente. Por dentro, é só um nome que aponta para um commit e anda sozinho a cada commit novo.O que é um Branch
branch padrão (default branch)O branch principal do repositório, criado pelo git init: hoje quase sempre main (antigamente, master).git init

C

TermoO que éAula
checkoutO comando antigo "faz-tudo": troca de branch, visita commits e restaura arquivos. Hoje dividido em switch e restore.git checkout
cherry-pick (colher a cereja)Copiar um commit específico de outro branch para o atual.cherry-pick
clean (limpar)Apagar arquivos novos, não rastreados: git clean -n (mostra), -f (apaga).git clean
clone (clonar)Baixar uma cópia completa de um repositório remoto, com todo o histórico.git clone
commit (registro, "fotografia"; verbo: commitar)Uma fotografia do projeto inteiro num momento, com autor, data, mensagem e um hash. Também o ato de gravá-la: git commit.git commit
commit de mergeUm commit com dois pais, que junta dois branches.Merge de Três Vias
configAs configurações do Git (nome, e-mail, editor…), em três níveis: sistema, global e do repositório.Configurações
conflito (merge conflict)Quando os dois lados mudaram a mesma parte de um arquivo e o Git não sabe qual escolher: ele marca o trecho com <<<<<<<, ======= e >>>>>>> e pede ajuda.Conflitos
Conventional CommitsUm padrão de mensagens: feat: …, fix: …, docs: ….Conventional Commits

D

TermoO que éAula
detached HEAD (HEAD destacado)Quando o HEAD aponta direto para um commit, e não para um branch (ao visitar um commit antigo). Commits feitos assim ficam "soltos" se você sair sem criar um branch.HEAD Destacado
diff (diferença)As linhas que mudaram entre duas versões: - saiu, + entrou.git diff

F

TermoO que éAula
fast-forward (avanço rápido)Um merge em que o branch de destino não mudou: o Git só "avança o ponteiro", sem criar commit de merge.Fast-forward
fetch (buscar)Baixar as novidades do remoto sem mexer nos seus branches (elas ficam em origin/main).git fetch
fork (bifurcação)No GitHub: uma cópia de um repositório de outra pessoa na sua conta, para você mexer e depois propor mudanças.Fork
force push (envio forçado)Um push que sobrescreve o histórico do servidor. Use sempre --force-with-lease.push --force-with-lease

G

TermoO que éAula
GitO programa de controle de versão, que roda no seu computador.O que é Git
.git (a pasta)A pasta escondida, dentro do projeto, onde o Git guarda todo o histórico e as configurações do repositório. Apagá-la apaga o histórico.git init
.gitattributesArquivo que diz como tratar certos arquivos (fim de linha, binários, LFS)..gitattributes
.gitignoreArquivo com os nomes e padrões de arquivos que o Git deve ignorar..gitignore
GitHubUm site que hospeda repositórios Git e acrescenta pull requests, issues, Pages, Actions… (GitLab e Bitbucket são parecidos).Git × GitHub
GitHub ActionsAutomação do GitHub: rodar testes ou publicar algo a cada push.GitHub Actions
GitHub PagesHospedagem gratuita de sites estáticos direto de um repositório.GitHub Pages
ghO programa de linha de comando do GitHub (GitHub CLI).GitHub CLI

H

TermoO que éAula
hash (SHA, id do commit)O código de 40 caracteres que identifica um commit (152d79c53b87…); os 7 primeiros (152d79c) costumam bastar.O Hash do Commit
HEAD"Onde você está": aponta para o branch atual (que aponta para o último commit dele). HEAD~1 = um commit antes.O que é HEAD
hook (gancho)Um script que o Git roda sozinho num momento (antes do commit, antes do push…).Git Hooks
hunk (pedaço)Um bloco de linhas mudadas dentro de um diff, que começa com @@. O git add -p pergunta um por um.git diff

I

TermoO que éAula
indexOutro nome da área de preparo (é o arquivo .git/index).A Área de Preparo
issue (questão, chamado)No GitHub: um registro de bug, ideia ou tarefa, com conversa.Issues

L

TermoO que éAula
LFS (Large File Storage)Extensão para guardar arquivos grandes (vídeos, imagens pesadas) fora do histórico normal.Git LFS
log (registro, diário)A lista dos commits: git log.git log

M

TermoO que éAula
main / masterOs nomes mais comuns do branch principal. main é o padrão do GitHub desde 2020; master ainda aparece em projetos antigos.git init
merge (mesclar, juntar)Trazer o trabalho de um branch para outro.git merge
mensagem de commitO texto que explica o commit: um título curto (até ~50 caracteres), no imperativo, e, se precisar, um corpo depois de uma linha em branco.Boas Mensagens

O

TermoO que éAula
originO apelido padrão do remoto de onde você clonou. É só um nome: dá para trocar.git remote
origin/main (remote-tracking branch)A cópia local de como estava o main do servidor no último fetch. Você não commita nele.git fetch

P

TermoO que éAula
pai (parent)O commit anterior a um commit. O primeiro commit não tem pai; um commit de merge tem dois.Como o Git Guarda
pull (puxar)fetch + juntar (merge ou rebase) no branch atual, num comando só.git pull
pull request (PR, pedido de incorporação; no GitLab, merge request)No GitHub: um pedido para juntar um branch em outro, com revisão e conversa.Pull Request
push (empurrar, enviar)Mandar seus commits para o repositório remoto.git push

R

TermoO que éAula
READMEO arquivo de apresentação do projeto (em geral README.md, em Markdown), mostrado na página do repositório no GitHub.O README
rebase (mudar a base)Reaplicar os commits de um branch em cima de outro ponto, deixando o histórico em linha reta. Cria commits novos.git rebase
ref (referência)Qualquer nome que aponta para um commit: branch, tag, HEAD, origin/main.O que é HEAD
reflog (diário das referências)O histórico de tudo por onde o HEAD passou, até o que sumiu do log. A rede de segurança para recuperar commits.git reflog
remote (remoto)Outra cópia do repositório, em geral num servidor como o GitHub, com um apelido (origin).Repositório Remoto
repositório (repo)O projeto com todo o seu histórico: a pasta do projeto mais a .git.git init
rerere"Reuse recorded resolution": o Git lembra como você resolveu um conflito e repete a solução.Configurações
resetMover o branch atual para outro commit, com três modos (--soft, --mixed, --hard).git reset
restore (restaurar)Descartar mudanças de um arquivo ou tirá-lo da área de preparo (--staged).git restore
revert (reverter)Criar um commit novo que faz o contrário de um commit antigo. O jeito seguro de desfazer o que já foi enviado.git revert

S

TermoO que éAula
squash (espremer)Juntar vários commits num só.squash
SSH (chave SSH)Um par de chaves (pública e privada) para o GitHub reconhecer você sem senha.Chave SSH
stash (esconderijo)Uma gaveta onde você guarda mudanças não commitadas para depois: git stash / git stash pop.git stash
staged / unstaged (preparado / não preparado)Mudança que está / não está na área de preparo.git status
submódulo (submodule)Um repositório Git dentro de outro, preso a um commit.Submódulos
switch (trocar)Trocar de branch (git switch) ou criar e trocar (git switch -c).git switch

T

TermoO que éAula
tag (etiqueta)Um nome fixo para um commit, em geral uma versão (v1.0). Diferente do branch, não anda.git tag
token (de acesso pessoal)Uma "senha" gerada no GitHub para usar no lugar da senha da conta no HTTPS.HTTPS e Token
tracked / untracked (rastreado / não rastreado; nas mensagens, "não monitorados")Arquivo que o Git já conhece (está em algum commit ou na área de preparo) / arquivo novo, que o Git só vê de longe.git status
tree (árvore)O objeto que guarda uma pasta: a lista de arquivos (blobs) e subpastas (outras árvores).Como o Git Guarda
três vias (three-way merge)O merge que compara três versões (os dois lados e o ancestral comum) e cria um commit de merge.Merge de Três Vias

U

TermoO que éAula
upstream (branch de rastreamento)O branch do remoto que um branch local acompanha (main → origin/main). É ele que deixa o git push e o git pull funcionarem sem argumentos. Em forks, "upstream" também é o apelido comum do repositório original.upstream

W

TermoO que éAula
working tree (pasta de trabalho, working directory)Os arquivos que você vê e edita na pasta do projeto, fora da .git.A Área de Preparo
worktreeUma pasta de trabalho extra, ligada ao mesmo repositório, para ter dois branches abertos ao mesmo tempo.git worktree

Experimente

Muitos termos do glossário aparecem numa olhada no repositório. O asterisco do git branch marca o branch para onde o HEAD aponta.

Missão: liste os branches do repositório e descubra em qual deles o HEAD está (o que tem o *).
