Convenções
  • arquivo, branch, URL, HASH: troque pelo nome de verdade. HASH = os 7 primeiros caracteres do commit, que o git log --oneline mostra.
  • ⚠ = pode perder trabalho não commitado. Leia a aula antes da primeira vez.
  • Na dúvida, rode git status: ele diz onde você está e sugere o próximo comando.

O ciclo, em uma sessão

Do zero ao GitHub, com a saída real do Git da Ana. As três áreas: a pasta (onde você edita) → git add → a área de preparo → git commit → o histórico → git push → o GitHub.

$ mkdir receitas
$ cd receitas
$ git init
Repositório vazio Git inicializado em  /home/ana/receitas/.git/
$ echo '# Receitas da Ana' > README.md
$ git status --short
?? README.md                                    « ?? = novo, o Git ainda não conhece
$ git add README.md
$ git status --short
A  README.md                                    « A = adicionado à área de preparo
$ git commit -m 'Primeiro commit'
[main (root-commit) fe996fb] Primeiro commit    « branch, hash e mensagem do commit
 1 file changed, 1 insertion(+)
 create mode 100644 README.md
$ git remote add origin https://github.com/ana-souza/receitas.git
$ git push -u origin main
Enumerating objects: 3, done.                   « o progresso do envio (o terminal do guia não mostra)
Counting objects: 100% (3/3), done.
Writing objects: 100% (3/3), 231 bytes | 231.00 KiB/s, done.
Total 3 (delta 0), reused 0 (delta 0), pack-reused 0 (from 0)
To https://github.com/ana-souza/receitas.git
 * [new branch]      main -> main                « o main foi criado no GitHub
branch 'main' set up to track 'origin/main'.    « dali em diante, basta "git push"

(Português e inglês misturados: a tradução do Git que vem no Ubuntu é parcial, e as saídas aparecem aqui exatamente como saíram. Veja a nota em Seu Primeiro Commit.)
